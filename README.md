# 🛍️ Sistema de Desconto Progressivo

![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)
![GitHub](https://img.shields.io/badge/github-%23121011.svg?style=for-the-badge&logo=github&logoColor=white)

Um programa em Python desenvolvido para calcular descontos automáticos com base no valor total de compras em uma loja online. 💡

## 📋 Regras de Desconto
* **Menor que R$ 200,00:** Desconto de `5%`
* **De R$ 200,00 até R$ 299,99:** Desconto de `10%`
* **R$ 300,00 ou mais:** Desconto de `15%`

1. Certifique-se de ter o Python instalado.
